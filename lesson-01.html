Module 01

Agent Fundamentals

The core idea: how a tool-using LLM loop becomes an autonomous worker.

1. What is an agent?

A large language model alone can only produce text. An agent is a model plus a loop that lets it call tools (run commands, read files, browse the web), observe the results, and act again — repeating until a task is done. Hermes Agent packages that loop with a rich, provider-agnostic tool layer.

2. The tool-calling loop

Every turn works the same way: send the conversation plus available tool schemas to the model; if it returns tool calls, execute them and feed the results back; when it stops calling tools, that final message is your answer.

while budget remains:
    response = model(messages, tools)
    if response.tool_calls:
        for call in response.tool_calls:
            result = execute(call)
            messages.append(tool_result(result))
    else:
        return response.content   # final answer
Try it: run hermes in a terminal and ask it to create a file and read it back. Watch the tool calls it makes — that loop is the whole point of the course.

3. What this module covers

  • The provider-agnostic model layer (any LLM, swap mid-workflow)
  • How tools are discovered and executed per turn
  • Session, context, and prompt-caching invariants
  • Your first end-to-end agent task
