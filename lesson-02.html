Module 02

Tool Calling & MCP

From built-in tools to plugging in external Model Context Protocol servers.

1. Defining a tool

Every tool is a JSON schema: a name, a description, and typed arguments. The model reads the schemas and decides which tool fits the current step. Hermes ships a rich set (terminal, files, web, browser, and more) and you can extend it with MCP servers or your own tools.

{
  "name": "search_files",
  "description": "Find files or content by pattern",
  "arguments": { "pattern": "string", "path": "string" }
}

2. Model Context Protocol

MCP lets you attach external tool servers that expose capabilities the agent wasn't built with. A single config line can give your agent access to new data sources and actions without changing the core.

Build it: run hermes mcp to list and add MCP servers, then ask the agent to use a tool that only that server provides.
